# Santri360 — Aset Rilis

Repo ini **hanya menyimpan berkas rilis** (APK & AAB) Santri360. Kode sumber tidak ada di sini.

## Unduh

Buka tab [Releases](../../releases). Tiap rilis berisi:

- `santri360-<tenant>-<versi>.apk` — untuk dipasang langsung di Android
- `santri360-<tenant>-<versi>.aab` — untuk diunggah ke Play Console

## Catatan

- APK ditandatangani dengan keystore rilis resmi; jangan pasang APK dari sumber lain.
- Berkas di sini dibuat otomatis oleh pipeline rilis aplikasi mobile.
